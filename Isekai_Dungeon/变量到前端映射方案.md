## 一、首页顶部状态栏 (`#phase-row`)

### 左侧阶段文本（自上而下匹配，命中即停）

```
① 进程.阶段 === "创角阶段"     → "创角阶段"

② 进程.阶段 === "地下城攻略阶段"
   ├─ 地下城攻略状态.是否攻略结算中 → "地下城攻略阶段 · 结算中"
   ├─ 地下城攻略状态.是否攻略败北中 → "地下城攻略阶段 · 败北中"
   ├─ 战斗状态.是否战斗结算中       → "地下城攻略阶段 · 战斗结算中"
   ├─ 战斗状态.是否战斗中            → "地下城攻略阶段 · 战斗中"
   ├─ 地下城攻略状态.是否休整中      → "地下城攻略阶段 · 休整中"
   ├─ 地下城攻略状态.是否准备完毕    → "地下城攻略阶段 · 探索中"
   └─ 否                           → "地下城攻略阶段 · 准备中"

③ 进程.阶段 === "日常阶段"
   → 显示: "日常阶段"
   ├─ 大型事件.进行中           → 追加 " · {大型事件.名称}"
   └─ 系统状态.待处理事件 有 key → 追加 " · {key1} · {key2} ..." (遍历所有 key)
```

### 右侧经验/金币栏
| 显示 | 变量 |
|---|---|
| F级 · 新人冒险者 | `主角.冒险者信息.冒险者等级` + `冒险者称号` |
| Lv.5 / 经验条 | `主角.当前状态.等级` + `经验值` |
| 1,280 G | `主角.当前状态.金币` |
