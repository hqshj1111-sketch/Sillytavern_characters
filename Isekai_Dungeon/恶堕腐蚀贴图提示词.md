# 恶堕腐蚀角贴图 — AI 生成提示词

## 素材策略

**8×8 网格（64 张）一次生成**，每格一张独立的不规则角落腐蚀贴图。前端随机取用，让四角每次加载都有微妙差异的有机感，不会机械重复。

- 每格为正方形，中央 60-70% 留白（后续去背变透明）
- 腐蚀图案从角落向中心辐射，越靠近中心越淡
- 64 张之间在枝蔓走向、裂纹分布、细节疏密上有自然随机差异

## 图像规格

- **格式**：PNG，8×8 网格排列
- **单格**：200×200 或 256×256
- **整体**：1600×1600 或 2048×2048
- **透明区域**：每格中央 60-70% 留纯白（供后续批量去背）

## 前端使用方式

```css
/* 从 8×8 大图中定位单个格子 */
.corner-img {
  background-image: url('corruption-grid.png');
  background-size: 800% 800%; /* 8×8 */
}
.cell-0-0 { background-position: 0% 0%; }
.cell-1-0 { background-position: 14.28% 0%; }
/* ...共64个位置 */

/* 旋转覆盖四角 */
.corner-tl { transform: rotate(0deg); }
.corner-tr { transform: rotate(90deg); }
.corner-br { transform: rotate(180deg); }
.corner-bl { transform: rotate(270deg); }

/* 恶堕等级控制透明度 */
.corner-overlay { opacity: calc(var(--corrupt) * 0.11); }
```

前端加载时从 64 格中随机选 4 个分别放到四角，每次页面刷新都有微妙差异。

## 等级区分

同一张图用 opacity 控制：

- Lv.0 → opacity: 0
- Lv.3 → opacity: 0.33
- Lv.6 → opacity: 0.66
- Lv.8 → opacity: 0.88
- Lv.9 → opacity: 1 + CSS pulse 呼吸动画
