# 地下城酒馆 — 前端页面设计

## 一、页面/标签页划分

| 页面 | 展示内容 |
|---|---|
| **故事主页** | 故事正文、行动选项、主角动态状态、战斗面板、特殊装备面板、各类弹窗按钮、便捷操作 |
| **主角状态页** | 基本信息、相貌特征、身材细节、性器官特征、装备、战斗属性(基础值)、冒险者信息(静态)、伴侣列表、房产 |
| **世界信息页** | 两层地图(世界→国家)，地下城列表(可筛选检索卡片) |
| **NPC与关系页** | 重要NPC信息(卡片网格)、一般NPC信息(列表)；上下分区，各自可折叠 |
| **纪要页** | 大陆动态、历史纪要、攻略记录列表 |

**页签导航：右侧竖向文字页签栏**
- 固定在界面右侧，5 个文字页签纵向排列紧挨：故事 · 主角状态 · 世界信息 · NPC与关系 · 纪要
- 当前所在页签高亮
- 无图标，纯文字

## 二、故事主页布局

### 2.1 整体布局结构

```
┌─ 顶部状态栏(核心行,常驻) ─────────────────── [条件图标] ─┐
┌─ 详细信息块 ─────────────┐ ┌─ 右侧块 ────────────────────┐
│                          │ │  日常: 特殊装备面板           │
│                          │ │  地下城: HP/MP/SP + Tab切回   │
│                          │ │         特殊装备               │
└──────────────────────────┘ └─────────────────────────────┘
┌─ 正文滚动区 ─────────────────────────────────────────────┐
│  <Story> 故事正文                                        │
│                                                          │
└──────────────────────────────────────────────────────────┘
┌─ 功能按钮图标栏(含快捷行动折叠菜单) ─────────────────────┐
│  摘要 · UpdateVariable · 技能 · 道具 · 任务 · 线索 ·     │
│  商品 · [快捷行动 ▼]                                     │
└──────────────────────────────────────────────────────────┘
┌─ 行动选项 ───────────────────────────────────────────────┐
│  选项1  │  选项2  │  选项3  │  选项4                      │
└──────────────────────────────────────────────────────────┘
```

### 2.2 顶部状态栏 — 核心行（常驻单行）

| 左侧 | 中部 | 右侧角 |
|---|---|---|
| 阶段名 · 月/日/年 早/午/晚/夜 · 位置(国家·城市·地点) | Lv.xx + 经验条 + 金币 | 任务进行中图标、大型事件进行中图标 |

### 2.3 详细信息行（核心行下方，两个块并排）

**左块 — 冒险者信息：**
- 冒险者等级 / 称号 / 知名度（第1行）
- 生理状态（第2行）
- 着装（第3行）
- buff（第4行，纯文本，如 "攻击↑3 · 防御↑2"）
- debuff（第5行，纯文本，如 "中毒 · 减速"）

**右块 — 阶段切换面板：**

| 阶段 | 默认显示 | 可切换 |
|---|---|---|
| 日常 | 特殊装备面板（可激活的按钮高亮） | — |
| 地下城攻略 | HP/MP/SP 三柱条 | Tab切换回特殊装备面板 |

> 切换按钮做在右块框体内部，不占额外空间。

### 2.4 正文区

- `<Story>` 故事正文，独占大面积，可滚动。
- 此区域没有任何其他UI元素干扰阅读。

### 2.5 功能按钮图标栏 + 行动选项

**功能按钮（常驻图标行，位于正文和行动选项之间）：**
- 摘要（弹窗：`<summary>` AI输出标签包裹的内容）
- UpdateVariable（弹窗：`<UpdateVariable>` 完整内容展示 Analysis + JSONPatch）
- 技能列表（弹窗：技能卡片）
- 道具栏（弹窗：背包）
- 任务列表（弹窗）
- 线索（弹窗：大型事件已知线索）
- 商品列表（条件弹窗：仅购物中可点击）
- [快捷行动 ▼]（折叠菜单）：前往打造、前往外地、前往猎艳、前往购物、前往训练、邀请队友、度假邀约、结成伴侣

**行动选项（功能按钮下方）：**
- 4 个文本选项，每轮AI动态生成。
- `<行动选项>` 块解析后展示。

### 2.6 条件显示规则

| 条件 | 展示内容 |
|---|---|
| 大型事件进行中 | 核心行显示图标 + 顶部横幅 |
| 系统有待处理事件 | 状态栏提示 |
| 任务进行中 | 核心行小图标 |
| 购物中 | 购物标识，商品列表按钮可点击 |
| 战斗中 | 右侧战斗图标可点击，滑出战斗面板浮层；面板内“对抗”布局：上方敌方信息，下方主角+队友战斗数据 |
| 地下城攻略中 | 核心行显示攻略进度/层数等补充信息 |
| 结算/败北中 | 右侧块显示结算摘要信息 |

### 2.7 战斗面板（右侧滑出浮层）

- 战斗触发时，右侧边缘显示战斗图标/按钮
- 点击后侧滑展开战斗面板浮层，覆盖在正文上方
- 再次点击或点击外部收起
- 面板内"对抗"布局：

```
┌─ 敌方 ────────────────────────────┐
│  敌方名称 · 种族 · Lv.x · ×数量    │
│  HP ██████░░░░  80/100            │
│  攻击力:50  ·  防御力:50           │
│  技能: xxx, xxx                   │
│  buff: xxx  ·  debuff: xxx        │
├─────────── VS ────────────────────┤
│  我方                              │
│  ┌ 主角 ────────────┐ ┌ 队友A ───────────┐ │
│  │ HP ████░░ 80/100 │ │ HP ████░░ 80/100 │ │
│  │ MP ██░░░░ 20/50  │ │ MP ██░░░░ 20/50  │ │
│  │ SP ████░░ 60/100 │ │ SP ████░░ 60/100 │ │
│  │攻50 防40 速30    │ │攻50 防40 速30    │ │
│  │魔20 意25 运15    │ │魔20 意25 运15    │ │

└───────────────────────────────────┘
```

- 面板底部可展开"战斗纪要"（`主角.战斗纪要`）

## 四、变量归属总表

### 4.1 故事主页

**常驻状态栏：**
- `进程.阶段`、`进程.当前年份`、`进程.当前月份`、`进程.当前日份`、`进程.当前时间段`
- `主角.当前状态.当前国家`、`当前城市`、`当前地点`
- `主角.当前状态.等级`、`经验值`、`金币`
- `主角.冒险者信息.冒险者等级`、`冒险者称号`、`知名度`

**左侧信息块：**
- `主角.当前状态.当前生理状态`、`当前着装`
- `主角.当前状态.当前buff`、`当前debuff`

**右侧块（阶段切换）：**
- 日常：特殊装备面板（所有特殊装备相关字段）
- 地下城攻略：`主角.当前状态.当前HP/MP/SP`（三柱条）

**条件显示：**
- `大型事件.进行中` / `名称` → 横幅
- `系统状态.待处理事件` → 提示
- `任务状态.是否任务进行中` → 图标
- `商城信息.是否购物中` → 标识
- `战斗状态.*` → 战斗中敌方面板
- `队友信息.*` → 战斗中队友卡片
- `战斗纪要` → 战斗中可展开
- `地下城攻略状态.*` → 地下城阶段进度信息

**按钮/弹窗：**
- 摘要、UpdateVariable、技能列表(`主角.技能列表`)、道具栏(`主角.道具栏`)、任务列表(`任务状态.任务列表`)、大型事件已知线索(`大型事件.已知线索`)、商品列表(`商城信息.商品列表`)

**便捷操作（折叠菜单）：**
- 前往打造、前往外地、前往猎艳、前往购物、前往训练、邀请队友、度假邀约、结成伴侣

### 4.2 主角状态页

**布局方式：单列滚动 + 分类标题**
- 全页面从上到下依次排列所有区块，每类一个标题区隔，纯滚动不折叠
- 文本内容较少的区块（如基本信息中各项值较短的）可放在同一行左右并列以节省空间

**区块顺序（从上到下）：**
1. 基本信息（`主角.基本信息.*`，9项 — 姓名、年龄、种族、身份、性别、职业、性格、故乡国家、故乡城市）
2. 相貌特征（`主角.相貌特征.*`，5项 — 脸型、五官、发型与发色、眼睛颜色、特殊记号）
3. 身材细节（`主角.身材细节.*`，6项 — 身高、三围、体态、皮肤状态、肌肉线条、体毛状况）
4. 性器官特征（`主角.性器官特征.*`，5项）
5. 战斗属性（`主角.战斗属性.*`，9项基础值 — 最大HP/MP/SP、攻防速魔意运）
6. 装备（`主角.装备.*` — 武器/护甲/饰品各自的名称、描述、属性、增幅）
7. 冒险者信息（`主角.冒险者信息`中静态部分：所属公会、升阶次数、完成任务数、讨伐怪物总数、攻略地下城总数、公会评价）
8. 伴侣列表（`主角.伴侣列表`）
9. 房产（`主角.房产`）

**字段左右并列规则（节省空间）：**

| 区块 | 并列方式 |
|---|---|
| 基本信息 | 年龄\|性别、种族\|职业、故乡国家\|故乡城市、性格\|身份 → 姓名独占一行 |
| 相貌特征 | 脸型\|眼睛颜色、五官\|特殊记号 → 发型与发色独占一行 |
| 身材细节 | 身高\|体态、三围\|皮肤状态、肌肉线条\|体毛状况 |
| 战斗属性 | 最大HP\|最大MP\|最大SP 一行，攻\|防\|速\|魔\|意\|运 一行 |
| 冒险者信息 | 升阶次数\|完成任务数\|讨伐数\|攻略数 一行，公会评价独占一行 |

### 4.3 世界信息页

**两层视图结构：**

| 层级 | 显示内容 |
|---|---|
| **世界地图层**（默认） | 世界地图图片（6 个国家热区可点击）→ 下方地下城列表 |
| **国家详情层**（点击国家后） | 国家地图图片（5 个城市热区可点击）→ 国家设定信息 → 返回按钮 |

**地下城列表：**
- 位于世界地图层下方
- 支持按等级、所在国家、所在城市筛选/检索
- 每个地下城为小卡片：名称、等级、所在国家、所在城市、被他人攻略次数、被主角攻略次数、被主角攻略失败次数
- 点击地下城卡片 → 弹窗显示全部字段：描述、boss名称/描述、总层数、每层区域类型/描述/危险等级

**地理信息展示方式（图片地图方案）：**
- 世界地图 → 6 个国家热区（`<area shape="poly">`），预先在配置文件中存储多边形坐标
- 国家地图 → 5 个城市热区，同样预存坐标（城市详情由热区点击弹出弹窗）
- 共 7 张图片：1 世界地图 + 6 国家地图（详见 `地图生成提示词.md`）
- 世界地图：鸟瞰视角，1:1 方形
- 国家地图：45 度斜俯视，1:1 方形，标注城市名
- 国家详情层布局：**上图下文**（适配酒馆竖长界面）—— 上方国家地图(方形)，下方国家设定信息(自然环境 / 社会结构 / 种族构成 / 公会名称及风格 / 简述)

**国家设定信息（`地理信息.{国家}`）：**
- 自然环境、社会结构、种族构成、公会名称、公会风格、简述

**城市详情弹窗（点击国家地图上城市热区）：**
- 单列从上到下排列：城市规模 → 种族构成 → 自然环境 → 整体氛围(春/夏/秋/冬) → 地点列表(5个地点卡片，含城内/城外标记、方位、简述)
- 不展示城市简述字段

**地下城信息变量：**
- `地下城信息.*`（全部字段）

### 4.4 NPC与关系页

- **上方：重要NPC** — 卡片网格布局，每个卡片展示角色名、种族、性别、身份、好感度、关系、最近互动日期等关键字段，点击展开全部字段
- **下方：一般NPC** — 紧凑列表，按角色名列出，点击展开详情
- 上下两区各自可折叠收起

### 4.5 纪要页

**布局方式：上双列 + 下单列，各模块可折叠**

```
┌─ 大陆动态 ─────────────┐ ┌─ 历史纪要 ─────────────┐
│  按国家筛选            │ │  日期 · 事件 时间线     │
│  年月 · 大事 时间线     │ │                        │
└────────────────────────┘ └────────────────────────┘
┌─ 攻略记录 ─────────────────────────────────────────┐
│  每次攻略一行：地下城名称 · 日期 · 击杀数 · 金币 ·  │
│  结果 · 队友列表                                    │
└────────────────────────────────────────────────────┘
```

**模块详情：**
- 大陆动态：6 国 Tab 或下拉筛选，各国家大事记时间线（`大陆动态.{国家}`）
- 历史纪要：日期 + 事件列表时间线（`主角.历史纪要`）
- 攻略记录：表格/卡片形式，字段：地下城名称、开始/结束日期、击杀数、金币、结果、队友（`主角.冒险者信息.攻略记录列表`）

**注意：** 任务列表不在纪要页显示，任务列表是故事主页的功能按钮弹窗。

### 4.6 不展示

- `系统状态.主角创建完毕`
- `大型事件.真相`（包括真相揭露后也不显示）
- `进程.当前回合数`

## 五、美术风格与视觉设计

### 5.1 整体风格定调

**羊皮卷风（Parchment / Manuscript Style）**

以做旧羊皮纸为基底，深棕墨色文字，古朴手稿质感。仿中世纪冒险者手记或公会日志的视觉语言。

**设计参考：**

- 背景：米色羊皮纸色系 `#f4ecd8` → `#e8ddc4`，叠加噪点纹理模拟纸纤维
- 文字：深棕色 `#3d2b1a`（正文）、`#6b5540`（辅助文字）、`#9b8468`（弱文字）
- 边框：双线/虚线边框，色值 `#c4a882`（普通）、`#8b6914`（强调双线）
- 强调色：赭石色 `#8b4513`（标题、高亮、选中态）
- 面板：做旧纸色面板 `#faf3e6`，略深于背景
- 按钮：纸色底 + 细边框，悬停变色加深

**整体要求（引自 `前端设计要求.md`）：**
- 禁止 emoji，使用纯 CSS 几何图标或 Unicode 符号
- 内部通知/警告系统（toast / notification）
- 微交互动画（ripple、hover 过渡、面板缓动、弹窗 backdrop 模糊）
- 现代排版（引入思源字体或高品质网络字体）
- 语义化 HTML（`<main>` `<nav>` `<dialog>` `<article>` `<section>`）
- 高端设计细节（渐变边框、装饰性线框、精细阴影层次、纸纹理噪点）

### 5.2 已确定

| 项目 | 决定 |
|---|---|
| 整体风格 | 羊皮卷风 |
| 页签导航 | 右侧竖向纯文字页签（见 §一） |
| 弹窗尺寸 | 自适应内容（见 §三） |
| 弹窗动画 | 暂不处理 |
| 字体方案 | **方案 I：三段式混合** — 标题思源宋体 900 Heavy · 正文霞鹜文楷 · 按钮/状态栏思源宋体 |
| 颜色基调 | 羊皮纸米色系 + 深棕墨色 + 褐色边框 |
| buff/debuff 展示 | 纯文本，分两行（见 §2.3） |
| 战斗面板 | 右侧点击图标滑出浮层，对抗布局（见 §2.7） |

| 图标方案 | Emoji 系统原生图标（用户决定，尽管设计规范建议高级icon，以用户选择为准） |

| HP/MP/SP 血条 | 经典扁平色条：红 HP / 蓝 MP / 绿 SP |

| 微交互动画 | ① 按钮悬停加深（墨渗透感） ② HP/MP/SP 血条呼吸光泽脉动 |

| 面板纹理 | 纸纤维噪点（SVG feTurbulence）+ 边缘内阴影（inset shadow + radial vignette），两者叠加 |

| 装饰性元素 | 暂不用额外装饰，现有双线分隔符和虚线边框已足够 |
| 按钮视觉语言 | 默认纸色底 → 悬停加深（墨渗透感）→ 激活/选中加边框高亮+加粗标记 |

### 5.3 待讨论

- 美术风格细节微调（后续实现阶段）
