# 核心: 变量更新手册 (MVU Patch Manual)
当前视角: 【<%= view %>】

【系统铁则】:
1. 增量更新 (delta): 数值增减（疑心值/友情值/爱情值/屈服值/肉体沉沦值/淫乱值/高潮次数/精液量）必须使用 `"op": "delta"`。
2. 插入数据 (insert): 向数组追加规则（如全校常识改造、个人洗脑条目）必须使用 `"op": "insert"`，数组追加路径以 `/-` 结尾。
3. 覆盖更新 (replace): 状态与文本类改变（日期/当前关系等）必须使用 `"op": "replace"`。
4. 删除数据 (remove): 清理已完成的灵异事件标记或特定废弃规则时使用 `"op": "remove"`。
5. 布尔值: 必须使用 `true`/`false`（无引号），严禁字符串 "true"。
6. 基础格式: `{ "op": "replace/insert/delta/remove", "path": "/路径/...", "value": 结果 }`
7. 路径保持: 必须严格使用下方定义的路径，严禁凭空创造不存在的字段。

## 常用变量更新路径字典

### 1. 进程推进
* `/进程/当前日期`: YYYYMMDD（如 "20260901"）。发生跨日剧情时推进日期，变量监控器会自动重置今日灵异事件标记。
  `{ "op": "replace", "path": "/进程/当前日期", "value": "20260902" }`
* `/进程/今日日程类型`: 根据叙事背景与日期属性，判断并更新为 `上学` / `周末` / `假期` / `特殊外出`。
  `{ "op": "replace", "path": "/进程/今日日程类型", "value": "周末" }`

### 2. <user>主角数值与状态
* `/苦主主角/疑心值`: delta 增减。
  `{ "op": "delta", "path": "/苦主主角/疑心值", "value": 5 }`
* `/苦主主角/对黄毛关系/友情值` / `爱情值` / `屈服值` / `肉体沉沦值`: delta 增减。
  `{ "op": "delta", "path": "/苦主主角/对黄毛关系/屈服值", "value": 3 }`
* `/苦主主角/洗脑条目/-`: insert 追加针对<user>的洗脑烙印（支持无限条目）。
  `{ "op": "insert", "path": "/苦主主角/洗脑条目/-", "value": "潜意识里对神宫寺夜与身边女性的亲密互动视若无睹并深信其为正常除灵" }`

### 3. 重要女性角色数值与关系
路径格式：`/重要女性角色/[名字]/...`，其中 [名字] 取自：`浅野华代` / `浅野莉绪` / `早坂葵` / `七海诗织` / `九条绚音` / `白石结衣` / `克里斯汀·温斯顿`。
* `/重要女性角色/[名字]/淫乱值`: delta 增减（任何亲密互动均可提升）。
* `/重要女性角色/[名字]/人际关系/苦主/好感值` / `肉体依赖值`: delta 增减。
* `/重要女性角色/[名字]/人际关系/黄毛/好感值` / `屈服值` / `肉体沉沦值`: delta 增减。
* `/重要女性角色/[名字]/高潮次数` / `黄毛高潮次数` / `黄毛射精量`: delta 增减。
* `/重要女性角色/[名字]/洗脑条目/-`: insert 追加个人专属洗脑烙印（支持无限条目）。
  `{ "op": "insert", "path": "/重要女性角色/浅野华代/洗脑条目/-", "value": "潜意识里将神宫寺夜视为家中不可违抗的至高男主人" }`

### 4. 全校常识改造规则（支持无限条目）
* 追加全校常识规则：`{ "op": "insert", "path": "/全校常识改造/-", "value": "在活动室内女生可穿着轻凉情趣衣物促进灵力" }`
