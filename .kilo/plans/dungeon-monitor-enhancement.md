## 一、现状诊断

### 对比 NudeLiveStreaming 监视器的缺失模块

| NudeLiveStreaming 模块 | 地下城对应需求 | 优先级 |
|---|---|---|
| processDateTimeWeather — 日期/天气/假期自动演进 | 年月日+时间段自动推进 | 🔴 高 |

| processEventPush — 随机事件推送 + 队列管理 | 待处理事件队列管理 (同名事件排队) | 🟡 中 |
| enqueueExistingEvent / pushEvent — 事件入队 | 同上 | 🟡 中 |
| processThresholdEvents — 跨越阈值事件 | 升级事件、知名度里程碑、冒险者等级晋升 | 🟡 中 |
| processLewdIncreaseOnSexCount — 性行为→淫乱度 | N/A (地下城无此设计) | ⚪ 无 |
| maintainExtensibleArrays — 数组维护 | buff/debuff 数组类型纠错 | 🟢 低 |
| processLiveViewers — 直播人数更新 | N/A | ⚪ 无 |
| processStreamEndRecords — 最高记录 | 单次攻略最高击杀数/最深楼层 | 🟢 低 |
| processFanSyncToJin — 粉丝联动 | N/A | ⚪ 无 |

## 三、监视器增强方案 (按优先级)

### Phase 1 — 核心阶段与时间管理 (必须)

#### 1.1 日期/时间段自动推进
- 需求：每次回合自增时，自动推进时间段
- 参考：NudeLiveStreaming processDateTimeWeather
- 逻辑：
  `
  时间段推进链: 早 → 午 → 晚 → 夜 → 早(+1日)
  日份进位: 日份>当月天数 → 日份=1, 月份+1
  月份进位: 月份>12 → 月份=1, 年份+1
  `

#### 1.2 阶段自动切换 — 进入地下城
- 需求：当「当前地下城名称」从空 → 非空
- 参考：NudeLiveStreaming 开播检测
- 操作：设置阶段=地下城攻略阶段, 初始化层数=1, 重置本次攻略临时计数器

#### 1.3 阶段自动切换 — 退出地下城
- 需求：当「是否攻略结算中」从 true → false
- 操作：设置阶段=日常阶段, 清空当前地下城名称, 清空敌方数据

#### 1.4 回合自增 (已有，融入统一流程)

---

### Phase 2 — 事件队列管理 (应该)

#### 2.1 待处理事件队列
- 参考：NudeLiveStreaming enqueueExistingEvent + pushEvent + 队列消费
- 功能：同名事件自动入队/出队、事件等待处理中标记维护

#### 2.2 战斗结束后敌方数据清理
- 检测「是否战斗结算中」true→false 时清空敌方名称/等级/HP等

---

### Phase 3 — 数值约束维护 (建议)

#### 3.1 HP/MP/SP 上限约束
- 需求：确保当前HP/MP/SP不超过最大值 (主角 + 所有队友)

#### 3.2 休整阶段自动恢复
- 需求：休整中每回合恢复 10% maxHP/maxMP/maxSP

#### 3.3 经验值溢出兜底处理
- 需求：当 exp >= 升下一级所需时自动升级 (战斗结算已处理基础逻辑，此为兜底)

#### 3.4 知名度里程碑检测
- 参考：NudeLiveStreaming processThresholdEvents
- 功能：检测知名度跨越 [0,50,200,500,1500,5000) 阶段时推送事件

---

### Phase 4 — 可选增强 (按需)

#### 4.1 buff/debuff 数组类型纠错
#### 4.2 单次攻略最高记录 (最高楼层、最高击杀)
#### 4.3 攻略结束后移除 HP=0 的队友

## 六、架构决策

统一在 VARIABLE_UPDATE_ENDED 处理：

`
onVariableUpdateEnded(variables):
  1. 初始化/快照检查
  2. 回合自增 (已有)
  3. 日期/时间段推进 (新增)
  4. 阶段检测与切换 (新增)
  5. 事件队列管理 (新增)
  6. HP/MP/SP上限维护 (新增)
  7. 休整恢复 (新增)
  8. 知名度里程碑 (新增)
  9. 保存快照 (已有)
`

保留 GENERATION_AFTER_COMMANDS 中的 onBeforeGeneration 用于用户指令预解析 (需要读取原始消息文本)。

去掉 lastProcessedTurn 状态机 — 地下城每层变量独立，不需要防二次处理。
