# CyberArena 前端状态面板实施计划

## 技术方案

采用正则替换 + 内联 HTML，对标 LittleHero 状态面板：

1. **触发标记**：复用 `<StatusPlaceHolderImpl/>`
2. **双正则**（对标 LittleHero 同机制）：
   - **隐藏正则**：匹配 `<StatusPlaceHolderImpl/>`，替换为空字符串 → `仅格式提示词: true`（对 AI 隐藏）
   - **渲染正则**：匹配 `<StatusPlaceHolderImpl/>`，替换为状态面板 HTML 文件 → `仅格式显示: true`（用户可见）
3. **数据读取**（对标 LittleHero 的 `renderPanelWithData` + `updateDOM` 模式）：
   ```js
   function getMvuInstance() {
     try { return window.Mvu || (window.parent && window.parent.Mvu) || (window.top && window.top.Mvu) || null; }
     catch (e) { return null; }
   }
   // 初始化
   const Mvu = getMvuInstance();
   if (Mvu && Mvu.events) {
     // 监听变量更新事件，实时刷新面板
     document.addEventListener(Mvu.events.VARIABLE_UPDATE_ENDED, (e) => {
       if (e.detail && e.detail.stat_data) { renderPanelWithData(e.detail.stat_data); }
     });
     // 首次渲染：从 MVU 获取当前数据
     const initData = Mvu.getMvuData({ type: 'message', message_id: -1 })?.stat_data;
     if (initData) renderPanelWithData(initData);
   }
   // 渲染函数用 updateDOM 做 DOM diff 增量更新，避免全量替换
   ```
4. **输出协议**：在 `[系统]_最终输出协议` 中追加指令，要求 AI 在每次输出末尾输出 `<StatusPlaceHolderImpl/>`

### 2. 更新 MVU 变量监控器 — 自动插入历史性斗记录

**文件**：`CyberArena/脚本/赛博擂台-MVU变量监控器.js`

在 `runStateMachine` 的幕间过渡检测处（当前约第 443 行），`_executeArenaReset` 调用之后，新增历史记录插入逻辑：

```js
// --- 擂台结算 → 幕间日常：插入历史记录 ---
if (curPhase === '幕间日常' && ['擂台结算', '胜利享用', '败北惩罚', '平局收场'].includes(prevPhase)) {
  ctx.set('系统状态.幕间回合计数', 0);
  this._executeArenaReset(ctx);
  this._insertBattleHistory(ctx, prevPhase);  // 新增
}
```

新增方法 `_insertBattleHistory(ctx, prevPhase)`：
- `对手名字`：`ctx.get('擂台状态.对手名字')` 或从 `ctx.getPrev()` 获取
- `结果`：胜利享用→"胜"，败北惩罚→"负"，平局收场→"平"，擂台结算→根据 prev 和 curr 积分变化推断
- `赛前积分` / `赛后积分`：prev data 中的积分 vs 当前积分
- `人气变化`：`(ctx.get('主角.擂台数据.人气') - ctx.getPrev('主角.擂台数据.人气'))` 或直接取 `prev.擂台状态.主角当前人气` 差值
- `信用点变化`：`(ctx.get('主角.经济.信用点') - ctx.getPrev('主角.经济.信用点'))`
- `对手段位`：`ctx.get('擂台状态.对手段位')`，若无则遍历 `记录.性斗士名录` 用对手名字匹配获取 `擂台段位`
- `性斗日期`：`${ctx.get('进程.当前年份')}年${ctx.get('进程.当前月份')}月${ctx.get('进程.当前日份')}日`
- 用 `"op": "insert"` + `"/记录/历史性斗记录/-"` 追加记录
