# 迷香恶堕 — 角色卡设计方案

## 一、项目概述

新建一张独立角色卡，暂定名为「迷香恶堕」。主题：furry 小英雄 × 恶堕 × 气味癖。玩家扮演怪人组织成员，利用雄臭能力和欲望之泥，将敌对正义组织的 4 名小英雄逐步恶堕。

相比 SummerTown 的核心新增：**视角切换系统** — 玩家可通过设置变量值，以第一人称扮演怪人或任意一位小英雄。

## 二、从 SummerTown 学习的词条写法总结

### 2.1 词条分类体系
- `[Initvar]` — 变量初始化，绿灯触发，在角色定义之前插入（最先执行）
- `[设定]` — YAML 文件，纯静态文字，叙事风格 / 世界观 / 地图等
- `[描述]` — EJS 模板文本，从变量读取数据动态渲染（角色档案 / 生理状态 / 动态档案）
- `[系统]` — EJS 模板文本，控制流程（阶段广播 / 输出协议 / 战斗引擎）
- `[事件]` — EJS 模板文本，特定条件触发的事件处理（恶堕 / 高潮 / 特殊事件）
- `[MVU]` — EJS 模板文本，变量更新操作手册
- `[记录]` — EJS 模板文本，历史事件记录
- `[可选]` — EJS 模板文本，辅助选项生成

### 2.2 插入策略
- `角色定义之前` + 递增 order → 在系统提示词顶端逐层叠加世界观/设定
- `指定深度 @ 系统 depth=0` + 递增 order → 在对话层中隐蔽注入指令
- order 值越低越早注入（角色定义之前的 order 100-200 先于 system depth 0 的 order 90-100）

### 2.3 EJS 模板模式
- `<%_ ... _%>` 代码块执行不输出
- `<%= ... %>` 输出变量值
- `getvar('stat_data')` 读取变量系统
- `_.get()` lodash 安全路径取值
- 条件渲染根据阶段/状态动态输出不同 AI 指令

### 2.4 最终输出协议模式
- 固定输出格式：正文 → `<UpdateVariable>` 块 → `<行动选项>` 块
- UpdateVariable 内含 `<Analysis>` + `<JSONPatch>` 双区块
- JSONPatch 使用标准 RFC 6902 格式

### 3.2 关键设计要点
- **runSanitizer**: 数据清洗，布尔值修正、数值限幅、非法阶段修正

- **VARIABLE_UPDATE_ENDED**: AI 输出后触发监控，由 `.tick()` 处理

## 四、世界观设定（方案推荐）

### 4.1 基本设定
- **世界**: 全都是 furry 的现代世界。无人类。科技水平等同当代。超能力、变身、神秘造物存在但稀有。
- **城市**: **新星市 (Nova City)** — 沿海的现代化中型城市，表面和平，暗流涌动。
- **正义组织**: **正义联盟** — 公开的民间英雄组织，受政府和民众信任。拥有识别和对抗怪人的科技与训练体系。
- **怪人组织**: 无特殊名称，就叫**怪人组织**。秘密犯罪组织，暗中制造"欲望之泥"引发社会动乱。
- **博士**: 怪人组织的首席科学家，欲望之泥的发明者，也是怪人主角的改造者。物种是兔子，头小小的，性格爱咋呼、傲娇。对怪人主角有绝对的掌控力。

### 4.2 欲望之泥
- 一种暗紫色粘稠**液态**物质，由博士发明。
- 普通人接触/吸入其挥发物后 → 内心欲望外露并急剧放大 → 失去理智 → 成为"怪人"（外形扭曲+本能驱动+欲望失控）
- 小英雄因其特殊体质/训练而对欲望之泥有较高抗性，但长期暴露/高浓度暴露仍会受影响。
- **释放方式**: 怪人主角体内的欲望之泥通过**体液**（汗水、唾液、精液等）释放，而非直接喷射。

## 五、角色设定

### 5.1 怪人主角（可扮演 #1）
- **背景**: 原本是碌碌无为的普通 furry 市民，被博士看中并改造为"最高杰作"。
- **能力**:
  - **雄臭散发**: 可主动控制释放令雄性着迷的气味。让人忍不住想闻，闻了之后会一直记住这种味道，不断想再闻，逐渐上瘾。浓度、范围、持续时间可变。**腋下和鸡巴处的雄臭味最为浓郁**，是气味的核心源头。
  - **欲望之泥释放**: 体内储存的欲望之泥通过体液（汗水、唾液、精液等）释放。
- **性格**: 对博士绝对忠心。其余性格、外貌、物种由玩家在创角时自定义。
- **叙事角色**: 故事的推动者，主动接触/伏击/诱导小英雄。

### 5.2 小英雄队长 — 夜守真白（猫，可扮演 #2）
- **姓名**: 夜守 真白（Yorimori Mashiro）
- **物种**: 猫（深灰色→黑色短毛，腹部/脸颊内侧渐变为浅灰白，短而密、光滑有光泽）
- **性格**: 乖巧可靠、成绩优秀的优等生。责任感强，对队友关怀备至。表面冷静，内心敏感。
- **年龄**: 14 岁
- **能力方向**: 战术指挥、高速机动力、夜视
- **相貌特征**: 小巧圆润面型，大直立耳。大而圆的琥珀色眼睛，粉色小鼻子。戴黑色圆框眼镜。
- **身材细节**: 155cm，纤细体态，肌肉线条不明显。
- **性器官特征**: 未发育完全的粉嫩小肉棒，薄包皮半包裹，龟头尖尖弯弯。后穴粉嫩紧致无毛。乳头小，粉色。生殖器周围毛发稀疏柔软。
- **性经验**: 完全童贞。从未自慰过。对性毫无概念，身体也几乎没有过勃起经验。是全员最"干净"的一个。

### 5.3 小英雄 — 虎渡太阳（白虎，可扮演 #3）
- **姓名**: 虎渡 太阳（Torawatari Taiyou）
- **物种**: 白虎（雪白底色+黑色条纹，体毛较厚实柔软）
- **性格**: 元气活泼、热情开朗的团队气氛担当。喜欢战斗和挑战，偶尔莽撞。乐观得近乎没心没肺。
- **年龄**: 15 岁
- **能力方向**: 近战格斗、力量强化、自愈能力
- **相貌特征**: 较大且棱角分明的面型，圆耳。冰蓝色大眼，黑色宽鼻。
- **身材细节**: 162cm，结实体态，肌肉线条已初步显现。
- **性器官特征**: 粗壮，与年龄不符的大肉棒，包皮已完全褪开、龟头充分露出。睾丸饱满。后穴紧致粉嫩。乳头小。体毛厚实柔软，黑色条纹分布在背部、肩膀和大腿外侧。

- **相貌特征**: 偏圆面型，垂耳。棕色大眼睛，总是水汪汪的，眼神怯生生的。

### 5.5 小英雄 — 风祭优羽（狐狸，可扮演 #5）

- **相貌特征**: 尖长狐系面型，大三角耳。狭长的金色眼睛，总是一副半睁半闭的慵懒神情。


### 6.3 核心变量 — 视角
- **变量路径**: `/视角`
- **可选值**: `怪人主角` | `夜守真白` | `虎渡太阳` | `槌谷陆` | `风祭优羽`
- **触发时机**: 玩家手动设置（通过变量面板或正则触发）
- **AI 行为变化**:
  - 第一人称叙事从此角色的视角出发
  - 只能感知此角色能感知的信息（不可全知其他角色所在地点发生的事）
  - 行动选项以此角色的立场生成
  - 其余角色由 AI 按各自设定自主行动（见 `[系统]视角叙事`）

### 6.4 核心变量 — 阵营归属 与 身份认知
- **阵营归属**（每小英雄 `恶堕状态.阵营归属`）: `正义` | `内应` | `彻底恶堕`（判定见 §10.3）
- **身份认知**（每小英雄 `人际关系.怪人主角.身份认知`）: `未知` | `怀疑` | `已识破`
  - `未知`: 该英雄视主角为普通市民（`怪人主角.伪装身份`），叙事不得泄露怪人身份
  - `怀疑`: 该英雄开始怀疑主角与怪人有关
  - `已识破`: 该英雄已知主角是怪人组织成员
- **不变量**: 气味沉溺阶段达到 `臣服` 时，该英雄的 `身份认知` 必须置为 `已识破`

## 七、叙事流程（无阶段控制）

本卡不设固定阶段机，采用自由叙事：

1. **创角（一次性）**: 由 `系统状态.主角创建完毕` 门控，完成怪人主角的物种/外貌/性格/伪装身份创建后置 `true`。
2. **自由叙事**: 由 `视角` 决定当前第一人称叙事角色；其余角色由 AI 按各自 `性格/日程/目标/人际关系` 自主行动。怪人事件、博士指令等不再有专用词条，改为 AI 依据角色日程与目标有机生成。
3. **推进线**: 气味暴露 → `气味沉溺度`↑ → 阶段跳转（无感→…→臣服）→ 臣服后转入 `内应` 状态 → `欲望之泥污染度`↑ → `彻底恶堕`。详见 §10。

## 十、气味癖与恶堕机制

### 10.1 雄臭释放控制
- 怪人可以主动开启/关闭雄臭释放
- **气味特征**: 让人忍不住想闻，闻过之后会一直记住这种味道，不断渴望再闻，逐渐上瘾
- **最浓郁位置**: 腋下、鸡巴处 — 近距离接触这些部位时沉溺度增长最快
- 浓度分 低/中/高 三档，消耗体力
- 范围：自身周边 (1m) / 房间级 (10m) / 建筑级 (50m)
- 目标被暴露后 → 每回合增加 `气味沉溺度`（根据距离、浓度、暴露时间计算 delta）
- **欲望之泥释放**: 通过体液（汗、唾液、精液等）释放。**雄臭暴露主要推 `气味沉溺度`，欲望之泥体液摄入主要推 `欲望之泥污染度`**
- 注：原 `[描述]气味散发系统` 独立词条已移除，浓度对照/气味描写指南并入本机制与 `[事件]气味沉溺度变化`

### 10.2 气味沉溺阶段
| 阶段 | 沉溺度阈值 | 表现 |
|------|-----------|------|
| 无感 | 0-19 | 正常状态，对雄臭无异常反应 |
| 好奇 | 20-39 | 觉得气味"有点好闻"，开始不自觉地靠近 |
| 渴望 | 40-59 | 主动闻嗅、心跳加速、无法集中注意力，脑中反复浮现那股味道 |
| 沉迷 | 60-79 | 理性大幅削弱、性欲被激发、对怪人产生依赖感，闻到雄臭就兴奋 |
| 臣服 | 80-100 | 完全沦陷、对怪人言听计从、以怪人的气味为生存必需 |

### 10.3 阵营归属 / 内应 / 彻底恶堕
- **判定**:
  - `正义`: 气味沉溺阶段 < 臣服
  - `内应`: 气味沉溺阶段 = 臣服 且 欲望之泥污染度 < 阈值(默认80) → 表面仍扮演正常小英雄，暗中为怪人组织服务、腐化正义联盟
  - `彻底恶堕`: 欲望之泥污染度 ≥ 阈值 → 彻底沦为怪人，不再/无法维持表面身份
- **内应行为**: 暗中破坏/渗透/策反队友 → 推进 `组织.正义联盟.基地沦陷进度`↑ 与 `警戒等级`↑（仅团队级，不做 per-hero 暴露风险变量）
- **身份伪装**: 主角以 `怪人主角.伪装身份` 接触英雄；`身份认知=未知` 时 AI 须以普通人身份描写主角，不得泄露怪人身份；主角可主动自曝身份
- **不变量**: 达到 `臣服` 阶段 → 该英雄 `身份认知` 置 `已识破`
- **内应视角叙事**（规则写入 `[系统]视角叙事` 词条）: 当 `视角` 为该内应小英雄时，正文需同时呈现其「表面言行」（对外伪装正常英雄）与 `<真实内心想法>`、`<真实生理表现>`（尖括号包裹，仅玩家/上帝视角可见，其余角色不可知）。建议用 `<内心>…</内心>` / `<生理>…</生理>` 显式标签，与结构标签 `<UpdateVariable>` 等区分。
